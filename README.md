### 🚀 Sobre mim
- 💼 **CTO no Grupo Villela** ([Villela-Tech](https://github.com/Villela-Tech)), com mais de 25 anos em tecnologia, de suporte e redes a gestão de TI e desenvolvimento de sistemas. Baseado em Porto Alegre.
- 🧑‍💻 Desenvolvo sistemas internos e plataformas com **TypeScript, Node.js, React, Next.js e PostgreSQL**. Para automação e dados, **Python**.
- 🔗 Integrações entre CRMs, ERPs e APIs com **Make.com, Bitrix24 e Pipedrive**.
- 🤖 Integro IA nos produtos: busca semântica, assistentes com LLM e APIs/servidores **MCP** para agentes de IA operarem os sistemas.
- 🛡️ Cuido de infraestrutura e segurança da informação: certificado **EXIN ISMP (ISO/IEC 27001)** e **PDPF (privacidade e proteção de dados)**.
- 📈 Nas horas vagas, robôs de trading com machine learning para cripto e Betfair.

## 🧩 Projetos em destaque

| Projeto | O que é | Stack |
|---|---|---|
| **Help Desk** | Central de atendimento self-hosted: tickets por e-mail, portal, live chat e WhatsApp, com base de conhecimento e busca híbrida | React · Express · Socket.io · PostgreSQL · LLM |
| **Kanban** | Board de projetos da equipe com relatórios de fluxo e API que agentes de IA operam via REST ou MCP | Next.js · Prisma · PostgreSQL · MCP · Docker |
| **Villela Shield** | Leitura de documentos, cálculo de capacidade de pagamento (CAPAG) e emissão de laudos | TanStack Start · React · AI SDK · Docker |
| **Vibe Safe** | Plataforma de desenvolvimento com IA com governança: gerar, validar, homologar e aprovar antes da produção | TypeScript · Docker · Agentes de IA |
| **GitHub Backup** | Backup diário de todos os repositórios (próprios, colaborações e organizações) com alertas | Python · launchd |
